# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Use GitHub's private security advisory to report vulnerabilities:
https://github.com/Orxaq/speqr/security/advisories/new

## Signing Keys
Semver tags on `main` are GPG-signed by the Operator (Steven Devisch).
Key rotation and emergency revocation procedures are managed by the Operator.
